# Odin 中文学习站

**The Odin Project Chinese Learning Companion**

面向中文学习者的 The Odin Project 学习辅助站，提供中文讲解、学习进度、学习伙伴与路线导航。

> **非官方项目声明**：本站是个人维护的学习辅助工具，与 [The Odin Project](https://www.theodinproject.com/) 官方**无隶属关系，未获官方授权或背书**。正课始终是官方原课：Assignment、Exercise、Knowledge Check 与 Project 都在官方页面完成，本站每课都提供直达入口。「The Odin Project」名称、课程结构与官方内容归其原权利方所有。

## 这个站是什么

一个**纯本地、零依赖、不联网**的静态学习站：把 The Odin Project Foundations 前 19 课写成中文自足讲解，并配一套完全跑在你自己浏览器里的学习系统（进度、复习、统计、成就、学习伙伴）。没有账号、没有后端、没有遥测，所有学习数据只存在你的设备上。

## 给谁用

- 正在（或准备）沿 The Odin Project Full Stack JavaScript 路线自学、但读英文原文吃力的中文学习者；
- 希望学习行为被真实记录——进度、时长、复习、成长可见——而不是读完就忘的人；
- 想要一个本地优先、隐私干净的学习工具的人。

完全零基础也可以从第 1 课开始；每课讲解不假设你先读过英文正文。

## 当前主要能力

- **前 19 课中文自足讲解**：为什么重要 / 中文正文 / 重要英文术语 / 代码示例 / 常见错误 / 官方任务入口 / 本站中文自测（自测不替代官方 Knowledge Check）。
- **路线导航**：Foundations 46 课地图（每课五种探索状态 + 4 个单元 Boss 综合自测），以及官方 Full Stack JavaScript 全路线 8 个 World / 197 课的结构总览（未开放内容明确标注、不可点）。
- **学习进度与复习**：完成状态由你主动勾选；有效学习时长、XP 与等级、连续学习天数；勾选「需要复习」进入 1 / 3 / 7 / 30 天复习阶梯，到期只提示、逾期不惩罚。
- **学习统计**：GitHub 风格 17 周热力图、个人最佳记录、最花时间的课；可打印一页学习总结或导出 Markdown。
- **学习伙伴**：右下角的小诺（昵称可自定义、可关闭；按钮上只有她的头像，点开面板才显示「学习助手 · 小诺」）随你的真实学习数据长出成长阶段，给今日建议与低干扰提醒。
- **收藏与装扮**：学习叶片只由学习行为获得（完全免费、无充值），用来解锁头像（面板 63 款可选：36 个原创几何头像 + 27 个学习伙伴形象头像）、头像框（28 款）、学习伙伴形象（含 14 个正式立绘角色与可换装的人形形态）、30 套页面主题。
- **成就系统**：61 个一次性成就（12 类）+ 6 族铜/银/金循环成就；每日/每周/每月挑战卡。
- **外部资料中文辅助**：官方指定的第三方文章与视频，给已核验的官方中文版链接，或本站原创中文速览与导读要点 + 英文原文链接；对许可明确为 CC 系列且没有官方中文版的 14 条来源，本站另提供采用与原作相同许可的中文精译（卡内附署名、来源、许可声明与译者说明）。只链接、不搬运、不代理。
- **8 张原创 SVG 概念图**：DNS、命令行目录树、HTML 结构等抽象概念的可视化辅助。

## 在线 Demo

在线版已通过 GitHub Pages 发布，打开即用、无需安装：

**https://ll96victor.github.io/the-odin-project-zh/**

> 纯静态站，没有任何后端，打开就能开始学。注意：浏览器的学习数据按「打开地址」隔离，在线版（`ll96victor.github.io`）与本地版（`127.0.0.1:8765`）各自保存一份互不相通的档案；换地址时用「导出 / 导入学习档案」搬家即可。

## 本地运行

只需要本机已有的 Python 3（Windows 从 [python.org](https://www.python.org/) 安装并勾选 Add to PATH；macOS 通常自带），**不需要安装任何依赖**：

| 系统 | 方式 |
| --- | --- |
| Windows | 双击 `start.bat` |
| macOS | 双击 `start.command`（首次被拦截时右键 → 打开） |
| 通用 | 终端运行 `python serve.py`（可加端口参数，默认 8765） |

或者克隆本仓库后运行启动脚本：

```sh
git clone https://github.com/ll96victor/the-odin-project-zh.git
cd the-odin-project-zh
python serve.py
```

脚本会在 `http://127.0.0.1:8765/` 启动一个**只允许本机访问**的静态服务并自动打开浏览器；不监听局域网、不安装任何东西。学习期间保持那个窗口开着，关窗或 Ctrl+C 即停止。

也可以直接双击 `index.html` 阅读课程（`file://` 模式），但浏览器在 `file://` 下无法可靠保存数据——页面会给出提示并禁用进度写入。**要记录进度请用启动脚本。**

**请始终用同一个地址打开**：`localhost` 与 `127.0.0.1`、不同端口在浏览器里是不同的存储空间，混用会看到不同的进度（用 `localhost` 打开时会自动跳回 `127.0.0.1`）。换地址时可用「导出 / 导入学习档案」搬家。

## 数据存储说明

- 全部学习数据（进度、XP、成就、叶片、昵称、头像、装扮、主题、设置、学习历史）保存在**这台设备浏览器的 localStorage** 里，本地优先：无账号、无云端、无同步服务。
- 随时可在「学习进度 → 学习档案」导出 JSON 档案自行保管，或导入到另一台设备 / 另一个地址。
- 导入按白名单校验；schema 迁移、导入、重置等高风险动作前会自动创建本地备份（保留最近 5 份）；读档失败时冻结写入、绝不覆盖你的原始数据。
- 清除浏览器缓存 / 站点数据会删掉本地档案——重要进度请定期导出留档。

## 隐私说明

- **无后端、无遥测、无统计上报**：页面自身不发起任何网络请求；只有你主动点击的官方课程与外部资料链接会在新标签页打开。
- 不收集账号、密码、token、cookie 或任何凭据；上传头像只在本地设备处理与保存。
- 学习数据只有你的浏览器能读到，站点代码无法上传它们（源码有机械断言禁止 `fetch` / `XMLHttpRequest` / cookie 访问）。

## 项目结构

```
index.html / lesson.html        两个页面骨架（首页 + 课程页）
style.css / tokens.css          全站样式与设计 token
*.js（24 个）                   运行时脚本：课程数据、进度引擎、UI、伙伴、主题等
assets/                         学习伙伴立绘（WebP）与原创概念图（SVG）
serve.py + start.bat/.command   本地启动脚本（Python 3 标准库，零依赖）
tests/                          Node 测试 + Python 服务冒烟 + 官方链接核验
sources.json                    19 课官方原文 SHA-256 指纹（内容核对用）
```

跑测试同样零依赖：`node tests/<名称>.test.cjs`（38 个）、`python tests/serve_test.py`；`python -X utf8 tests/check_links.py` 会联网核验官方课程链接。
