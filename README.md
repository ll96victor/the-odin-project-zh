# Odin 中文学习站

**The Odin Project Chinese Learning Companion**

面向中文学习者的 The Odin Project 学习辅助站，提供中文讲解、学习进度、学习伙伴与路线导航。

> **非官方项目声明**：本站是个人维护的学习辅助工具，与 [The Odin Project](https://www.theodinproject.com/) 官方**无隶属关系，未获官方授权或背书**。本站对官方 Full Stack JavaScript 全路线全部 197 课提供完整中文学习内容与官方 Assignment 的中文对照，可以在本站学完并自查；Project 课本站提供要求中文版、拆解与验收清单、不提供成品代码，项目提交、Discord 社区与其后课程在 TOP 官方进行，本站每课都提供官方直达入口。「The Odin Project」名称、课程结构与官方内容归其原权利方所有。

## 这个站是什么

一个**纯本地、零依赖、不联网**的静态学习站：把 The Odin Project Full Stack JavaScript 全路线（8 个 World / 197 课）写成中文自足讲解，并配一套完全跑在你自己浏览器里的学习系统（进度、复习、统计、成就、学习伙伴）。没有账号、没有后端、没有遥测，所有学习数据只存在你的设备上。

## 给谁用

- 正在（或准备）沿 The Odin Project Full Stack JavaScript 路线自学、但读英文原文吃力的中文学习者；
- 希望学习行为被真实记录——进度、时长、复习、成长可见——而不是读完就忘的人；
- 想要一个本地优先、隐私干净的学习工具的人。

完全零基础也可以从第 1 课开始；每课讲解不假设你先读过英文正文。

## 本地运行

只需要本机已有的 Python 3（Windows 从 [python.org](https://www.python.org/) 安装并勾选 Add to PATH；macOS 通常自带），**不需要安装任何依赖**：

| 系统 | 方式 |
| --- | --- |
| Windows | 双击 `start.bat` |
| macOS | 双击 `start.command`（首次被拦截时右键 → 打开） |
| 通用 | 终端运行 `python serve.py`（可加端口参数，默认 8765） |

或者克隆本仓库后运行启动脚本：

```sh
git clone https://github.com/ll96victor/the-odin-project-zh.git
cd the-odin-project-zh
python serve.py
```

脚本会在 `http://127.0.0.1:8765/` 启动一个**只允许本机访问**的静态服务并自动打开浏览器；不监听局域网、不安装任何东西。学习期间保持那个窗口开着，关窗或 Ctrl+C 即停止。

也可以直接双击 `index.html` 阅读课程（`file://` 模式），但浏览器在 `file://` 下无法可靠保存数据——页面会给出提示并禁用进度写入。**要记录进度请用启动脚本。**

**请始终用同一个地址打开**：`localhost` 与 `127.0.0.1`、不同端口在浏览器里是不同的存储空间，混用会看到不同的进度（用 `localhost` 打开时会自动跳回 `127.0.0.1`）。换地址时可用「导出 / 导入学习档案」搬家。

## 数据存储说明

- 全部学习数据（进度、XP、成就、叶片、昵称、头像、装扮、主题、设置、学习历史）保存在**这台设备浏览器的 localStorage** 里，本地优先：无账号、无云端、无同步服务。
- 随时可在「学习进度 → 学习档案」导出 JSON 档案自行保管，或导入到另一台设备 / 另一个地址。
- 导入按白名单校验；schema 迁移、导入、重置等高风险动作前会自动创建本地备份（保留最近 5 份）；读档失败时冻结写入、绝不覆盖你的原始数据。
- 清除浏览器缓存 / 站点数据会删掉本地档案——重要进度请定期导出留档。

## 隐私说明

- **无后端、无遥测、无统计上报**：页面自身不发起任何网络请求；只有你主动点击的官方课程与外部资料链接会在新标签页打开。
- 不收集账号、密码、token、cookie 或任何凭据；上传头像只在本地设备处理与保存。
- 学习数据只有你的浏览器能读到，站点代码无法上传它们（源码有机械断言禁止 `fetch` / `XMLHttpRequest` / cookie 访问）。
